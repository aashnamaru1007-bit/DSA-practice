# Curated DSA Problem List (Topic-wise)

**How to use this:** These problems exist on BOTH LeetCode and Striver's sheet — search by name on whichever is more convenient that day (same bucket, don't do both). Solve in order given (Easy → Medium) per topic. This isn't the complete universe of problems — it's a focused, high-value set matching what's actually asked in interviews (drawn from well-known curated lists like Blind 75/NeetCode 150 style selections).

## General Rules (recap)
- **Easy problems**: aim for ~70-80% solved with genuine independent effort before moving to Medium on that topic
- **1 topic at a time**: finish a topic's Easy→Medium set before starting the next topic's Easy set
- **Don't chase 100% of every list** — this is a strong, sufficient set; more problems within these topics (via random practice) only need to happen if you still feel shaky after this core set
- **Hard problems**: mostly deferred to your roadmap's Phase 3 (~Feb-Apr 2027), except a few noted above once you're comfortable with that topic's Medium level
- **Company-tagged problems**: once you reach Phase 3, revisit these same topics but filter LeetCode by "Microsoft/Google/Adobe" tags for company-specific practice
